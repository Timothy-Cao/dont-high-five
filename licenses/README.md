# Notices and provenance

The bundled Godot 4.7.2 engine supplies its own license text and third-party notices in the adjacent files. These were extracted from the actual engine using `tools/write_engine_notices.gd`.

Game models are original procedural Blender work; geometry, shaders and sound are generated by the project's code. See `art/README.md`. Unused image-generation sky references and historical art are not included in the standalone package.

The game source and original assets have no public distribution license selected here. Godot's engine license does not assign a license to the game.
